### Overview & Intent
This case study is a self-directed exploration designed to understand how business requirements map to ERP systems. The objective of this project was to:
* **Demonstrate a first-principles approach** to analyzing real-world business operations.
* **Practice translating operational bottlenecks** into structured system requirements.
* **Bridge the gap** between engineering problem-solving and business SaaS software consulting.
---
### Methodology & Approach
The project intentionally avoids force-fitting software onto a business. Instead, it uses a zero-software baseline to map an ideal workflow before evaluating ERPNext's native capabilities.

1. **Discovery & Business Analysis**
   * Conducted preliminary discovery to identify core operational friction points for Café Myriade.
   * Isolated **Inventory Replenishment** (*"When to buy, and how much?"*) as the primary operational challenge to address.

2. **Framework Definition**
   * Established a structured framework: **Problem Definition** $\rightarrow$ **Desired Outcome** $\rightarrow$ **Ideal Process** $\rightarrow$ **Data Requirements** $\rightarrow$ **Product Capabilities** $\rightarrow$ **ERPNext Fit**.

3. **Software-Agnostic Process Design**
   * Mapped the uncompromised, ideal replenishment lifecycle (**Monitor** $\rightarrow$ **Assess** $\rightarrow$ **Decide** $\rightarrow$ **Purchase** $\rightarrow$ **Receive** $\rightarrow$ **Update**) independent of any specific tool.

4. **ERPNext Capability Exploration**
   * Evaluated ERPNext’s documentation and core modules against the ideal process to identify natural feature fits (e.g., *Stock Ledger*, *Re-order Levels*) and highlight areas requiring further configuration or validation.

5. **Conclusions & Next Steps**
   * Documented initial findings and key implementation considerations prior to actual software deployment.
